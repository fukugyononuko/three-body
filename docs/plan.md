# 制作計画書：三体問題シミュレーター（Rust + WebAssembly）

副業のぬこの制作例その 4。天体が重力で引き合う「三体問題」（天体の数は 2〜8 に変えられる N 体問題）を、Rust で数値計算し、WebAssembly にしてブラウザで 3 次元に動かす。
見た目は、論文や研究室のページのように飾りの少ないものにする（白い紙に細い線の図。ダークモードにも対応）。文字は日本語の TeX 論文の標準（jsarticle）に合わせる：本文は Computer Modern Roman＋明朝体、見出しと太字は Computer Modern Sans（太字）＋ゴシック体。

## 1. 目的

| ID | 目的 |
| --- | --- |
| G-01 | 三体問題の面白さ（美しい周期解、予測できないカオス）を、触って確かめられる形で見せる |
| G-02 | 数値計算が「正しい」ことを、検証つきで示す（保存量、既知の解との一致） |
| G-03 | Rust・WebAssembly・Web ページを組み合わせて作れることを見せる |

## 3. 数値計算

| ID | 項目 | 内容 |
| --- | --- | --- |
| N-01 | 方程式 | 万有引力（ニュートン）、3 次元、天体の数 N = 2〜8。重力定数 G = 1 の無次元の単位。軟化（ソフトニング）はしない。N の上限は、色の見分けやすさを検証した配色が 8 色のため |
| N-02 | 積分法 1 | 古典的ルンゲ・クッタ法（RK4、刻み幅一定） |
| N-03 | 積分法 2 | ドルマン・プリンス法（RK45、刻み幅を誤差に応じて自動で変える） |
| N-04 | 積分法 3 | リープフロッグ法（速度ベルレ法、刻み幅一定、シンプレクティック） |
| N-05 | 保存量 | 全エネルギー、全運動量、全角運動量（ベクトル）を計算して表示する |
| N-06 | 刻み幅と許容誤差 | 刻み幅一定の方法（N-02、N-04）は刻み幅 h を、RK45（N-03）は許容誤差を、利用者が選べる |

- 天体が近づくと加速度が急に大きくなるので、刻み幅一定の方法（N-02、N-04）は誤差が増える。これも比較で見せる（S-04）。

## 4. 構成

| ID | 構成要素 | 内容 |
| --- | --- | --- |
| C-01 | 計算部分（Rust） | 外部クレートを使わず、標準ライブラリだけで書く。積分法とシナリオ、保存量 |
| C-02 | WebAssembly の窓口（Rust） | 関数を直接公開し、天体の位置などを共有メモリの配列で渡す（wasm-bindgen などは使わない） |
| C-03 | Web ページ（Astro + TypeScript） | 軌道を 4 面図（立体図＋xy・xz・yz への投影）で描く。立体図はドラッグと矢印キーで回せる。天体の数、初期値、積分法、刻み幅・許容誤差、再生速度、カオスのずらし方（Δx, Δy, Δz）を選べる。軌跡の長さ（0〜∞、古い部分ほど薄く描く）を選べる。全エネルギーの相対誤差をグラフで表示（軸のラベルは英語） |
| C-04 | 数式と文字 | 数式は TeX で書き、ビルドの時に MathML に変換する（Temml）。数式のフォントは STIX Two Math（OFL）。本文と見出しの欧文は CMU フォント（Computer Modern、OFL）。どのフォントも使う文字だけに絞って配信し（`scripts/subset-fonts.mjs`）、最初の画面で使う 2 つは preload する |

公開先：`https://fukugyononuko.github.io/three-body/`（GitHub Pages）

## 6. 検証

| ID | 検証 | 方法 |
| --- | --- | --- |
| V-01 | 二体問題（円軌道）で、1 周期後に元の位置に戻る | Rust のテスト。解析解と比較 |
| V-02 | 8 の字の解で、1 周期（約 6.326）後に初期状態に戻る | Rust のテスト（RK45、許容誤差を小さくして） |
| V-03 | 全運動量はどの積分法でも保たれる。全角運動量はリープフロッグ法で厳密に、RK45 で許容誤差の範囲で保たれる（刻み幅一定の RK4 は、接近があるとずれる） | Rust のテスト |
| V-04 | 全エネルギーのずれが、積分法ごとに想定の範囲に収まる（リープフロッグ法は長時間でも大きく増えない、など） | Rust のテスト |
| V-05 | ピタゴラスの三体問題で、最後に 1 つの天体が遠ざかっていく | Rust のテスト（既知の結果と照合） |
| V-06 | ページで WebAssembly が動き、キャンバスに描かれる。CSP 違反がない | e2e テスト |
| V-07 | Q-01〜Q-05 | e2e テスト、Lighthouse、予算の検査 |
| V-08 | 入力の検証（天体は 2〜8 個、質量が正、位置が重ならない、有限の数）、刻み幅を細かくすると RK4 の誤差が小さくなる、数式が style 属性なしの MathML で表示される | Rust のテスト、e2e テスト |
| V-09 | 8 の字の解を空間の中で傾けても、1 周期後に初期状態に戻る。傾いた二体の円軌道も 1 周期後に戻る | Rust のテスト |
| V-10 | 5 体の 3 次元の運動で、全運動量と全角運動量（ベクトル）が保たれる | Rust のテスト |

| V-12 | 天体の数を 2〜8 に増減でき、立体図をドラッグと矢印キーで回せ、3 次元の動きが投影図にも描かれる | e2e テスト |
| V-14 | S-08 の周期解が 1 周期後に初期状態に戻り（初期値の桁数に応じて 5 × 10⁻³ 未満）、蝶 I は 40 周期までに外れる | Rust のテスト（`tests/presets.rs`） |
| V-15 | S-09 の正三角形の解は 1 周期目は形を保ち、時刻 60 までに崩れる | Rust のテスト |

| V-17 | S-11 の一直線の解は 1 周期目は一直線を保ち、時刻 30 までに崩れる | Rust のテスト |
| V-18 | S-12 の惑星は 0.6〜0.8 AU を保ち、0.5 AU に置いた惑星は時刻 200 で 10 AU より遠い | Rust のテスト |
